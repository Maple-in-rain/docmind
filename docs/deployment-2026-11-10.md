## 验收中发现并修复的问题

1. 普通 RAG 和 Agent 曾将定性描述扩展成缺乏依据的成本或可靠性排名。收紧证据约束，复测中的代表性比较报告明确拒绝无依据排名。
2. Agent 初测 20 个任务中出现 39 次任务更新错误：模型改写了已完成步骤文本，导致字符串集合校验失败。改为从 0 开始的整数步骤编号，服务端映射回显示文本；新增边界回归，最终 20 条复测无工具错误。
3. Linux 无 `.env` 的暂存测试暴露重排单测依赖开发机真实 key。MockTransport 测试改用显式占位 key，测试统一隔离真实 API 凭据，最终两端均 126 项通过。
