# RAG（检索增强生成）简介

## 什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与大语言模型生成相结合的技术架构。它的核心思想是：在生成回答之前，先从外部知识库中检索与问题相关的文档片段，再将这些片段作为上下文交给大语言模型，使其基于真实资料作答。

## RAG 的工作流程

1. 文档解析：将 PDF、Word、Markdown 等格式的文档解析为纯文本。
2. 文本分块：把长文档切分成大小适中的片段（chunk），常见窗口为 256 到 768 个 token，块间可设置重叠以减少语义断裂。
3. 向量化：用 embedding 模型将每个文本块编码为高维向量，存入向量数据库。
4. 检索：用户提问后，将问题向量化并在向量库中做相似度检索，召回最相关的 top-k 个片段。
5. 生成：把召回的片段与用户问题一起组装成提示词，交给大语言模型生成带引用的回答。

## 为什么需要 RAG

大语言模型的知识截止于训练数据，存在"幻觉"（编造事实）与知识过时的问题。RAG 通过引入外部知识库解决了这两个痛点：答案有据可查、知识可以随时更新，且无需重新训练模型。此外，RAG 还能保护私有数据——敏感文档只存在于本地知识库，不需要喂给模型训练。

## 常见优化手段

- 混合检索：结合 BM25 关键词检索与向量语义检索，用 RRF（倒数排名融合）合并两路结果，兼顾专有名词精确匹配与语义泛化。
- 重排：召回阶段追求高覆盖，再用 reranker 模型对候选片段精排，提升排序质量。
- 分块策略调优：分块太大则召回精度下降，太小则语义碎片化，需要通过评估实验选择最优参数。
- 查询改写：利用对话历史把"那它呢"这类指代不明的追问改写为完整独立的问题。
