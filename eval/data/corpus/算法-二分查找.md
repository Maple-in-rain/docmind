# 二分查找

## 适用条件与思想

二分查找（Binary Search）要求数组**有序**，每次比较中间元素与目标值，排除一半候选区间，时间复杂度 O(log n)。n = 10 亿时最多比较约 30 次，这是它相比线性查找 O(n) 的数量级优势。

## 标准实现与边界

最经典的写法是左闭右开区间 `[lo, hi)`：

```python
def binary_search(nums, target):
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1
        elif nums[mid] > target:
            hi = mid
        else:
            return mid
    return -1  # 未找到
```

循环不变量：目标如果存在，一定在 `[lo, hi)` 内。`mid = (lo + hi) // 2` 在语言层面可能溢出（如 C 的 int 加法），安全写法是 `lo + (hi - lo) // 2`。

## 变形：查找边界

- **第一个 >= target 的位置**（lower_bound）：找到 `nums[mid] >= target` 时收缩 `hi = mid`，最后返回 `lo`。这是 C++ `std::lower_bound` 的语义。
- **第一个 > target 的位置**（upper_bound）：条件换成 `nums[mid] > target`。

掌握这两个"边界查询"模板后，统计等于 target 的个数就是 `upper_bound - lower_bound`，找最后一个等于 target 的位置是 `upper_bound - 1`。

## 常见错误

1. 死循环：`lo = mid` 而不收缩（mid 可能等于 lo），必须在 mid 计算时取上取整或让收缩侧变为 `mid + 1`。
2. 退出条件写 `lo <= hi` 时区间定义混乱，建议固定一种区间约定贯穿始终。
3. 未处理重复元素：二分查找返回的只是"某个"等于 target 的下标，不保证是第一个或最后一个。

## 扩展应用

二分不只在数组上：答案空间单调时可以对答案二分（如"最小化的最大值"类问题）；旋转排序数组（如 `[4,5,6,7,0,1,2]`）的搜索只需多判断 mid 落在哪一侧有序段；求平方根、判断完全平方数等都是二分的直接应用。
