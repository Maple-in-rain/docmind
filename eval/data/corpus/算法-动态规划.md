# 动态规划

## 核心思想

动态规划（Dynamic Programming）把原问题分解为**重叠的子问题**，每个子问题只求解一次并把结果存表，之后查表复用，避免重复计算。它适用于具有两个性质的问题：

1. **最优子结构**：原问题的最优解包含子问题的最优解；
2. **重叠子问题**：递归求解时同一子问题被多次遇到。

不具备重叠子问题的分治（如快速排序）不需要动态规划；不具备最优子结构的贪心（如找零钱在特定面额下）也不能用动态规划保证最优。

## 与记忆化递归的关系

记忆化递归（自顶向下）与动态规划（自底向上）本质相同：前者从原问题出发递归求解，遇到算过的子问题直接查表；后者先算小规模子问题，按依赖顺序递推填表。两者时间复杂度一致，动态规划通常常数更小且没有递归栈溢出风险。

## 经典例题：0-1 背包

容量为 W 的背包，n 件物品各有重量 w[i] 与价值 v[i]，每件物品只能选或不选（0-1），求能装下的最大价值。

状态定义：`dp[i][j]` = 前 i 件物品、容量 j 时的最大价值。
状态转移：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`（不选第 i 件 / 选第 i 件，容量不足时只能不选）。

```python
dp = [[0] * (W + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, W + 1):
        if j >= w[i - 1]:
            dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i - 1]] + v[i - 1])
        else:
            dp[i][j] = dp[i - 1][j]
```

时间复杂度 O(nW)，空间可用滚动数组优化到 O(W)——观察转移只依赖上一行，逆序更新一维数组即可。

## 经典例题：最长公共子序列

`dp[i][j]` = 字符串 s1 前 i 个字符与 s2 前 j 个字符的最长公共子序列长度。若 `s1[i] == s2[j]`，`dp[i][j] = dp[i-1][j-1] + 1`；否则取 `max(dp[i-1][j], dp[i][j-1])`。该算法是 diff 工具（如 git diff）的基础。

## 常见误区

- 状态定义不清晰：转移方程写不出来，多半是状态定义错了，应回到"用什么变量刻画当前局面"。
- 初始化遗漏：边界（第一行/第一列）需要显式初始化。
- 把所有递归都当 DP：没有重叠子问题就是普通分治。
